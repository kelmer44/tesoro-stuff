# 00401510 — inferred_AnimBank_LoadDeferredImages
Status: understood · Cluster: 1 · Depth: 9 · Convention: fastcall(AnimPlayer *this)

**Purpose (confirmed):** For a bank loaded in mode 2 (images skipped by AnimBank_Load), loads all its images from the archive now.

**Inputs:** this+0x14 load mode; this+0x20 image count; this+4 array of u32 file positions (recorded by AnimBank_Load, each pointing at the image's size field); global 00442064 (archive; its FILE* at +4).
**Outputs / state written:** only when mode == 2: for i in 0..count-1: fsetpos(file, offsets[i]); images[i] := AnimBank_LoadImage(file, arena = mode (2)). A failed allocation stores 0.
**Calls:** fsetpos 0041b600 (replaced), AnimBank_LoadImage 004015a0.
**Yields / blocks / timing:** disk reads.
**Edge cases:** no-op for other modes. Images are allocated from pool arena 2, the mode value, not from the arena used for the bank's tables. Calling it twice loads the images again (allocation grows each time).
**Evidence:** export/00401510.c; callers 00407b80, 00408800 (to check).
**Port:** engines/tesoro/core/animbank.cpp::AnimBank::loadDeferredImages (no-op unless the load mode is 2). The arena is not modelled.
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_anim.py + drivers/anim_driver.cpp): original Load/LoadImage/LoadDeferredImages/ScaleBrightness/SetRange run in Unicorn (fread/fgetpos/fseek/fsetpos, Archive_SeekEntry, the pool allocator and Clock_Now replaced by Python) on 700 synthetic animation files (0-9 sequences of types 0/1/2/4, 0-5 images of types 0/1/2/3/7, both pixel layouts, 5-5-5 and 5-6-5, load modes 0 and 2) vs engine AnimPlayer/AnimBank/AnimImage: load 700/700, header 700/700, flags 700/700, sequences 2509/2509, image positions 700/700, images after load 1396/1396, after deferred load 861/861, after brightness 832/832, SetRange 1748/1748. Five deliberate mutations of the port were all caught. Limits: synthetic data only (the shipped .DAT was not read); pool allocation/exhaustion is not modelled; the 5-5-5 overrun past the blob end and a sequence-less bank with images are not reproduced; pixel-first layouts are tested only without 5-5-5; item arrays shared by two spans are not tested; ranges reading past the sequence table are not tested.
**Open questions:** whether arena 2 is cleared by callers between uses.
