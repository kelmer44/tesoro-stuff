# 0040f590 — inferred_List_Ctor
Status: ported · Cluster: 27 · Convention: thiscall(List *this, int capacity, int arena, List *source) — RET 0xc

**Purpose (confirmed):** Creates an empty singly linked list with a fixed node capacity, or a second list sharing the node pool of an existing one.
**Memory layout (List = one pointer L to a 0x1c byte header):** L+0 pointer to the node block P; L+4 head link (first node, 0 = empty); L+0xc cursor (a node, initially the head, L+4); L+0x10 capacity; L+0x14 byte "at start" flag (0); L+0x18 the value the cursor last read. Node block P (capacity * 8 + 0x18 bytes): P+0 head of the free node list (0), P+8 bump pointer for unused nodes (P+0x10); nodes are 8 bytes: +0 next, +4 value.
**Outputs / state written:** without source: allocates the header (0x1c, zeroed) and P (zeroed) from the arena; with source: allocates a header only, L+0 := source's P (shared pool), L+0x10 := source's capacity, and the new list starts empty. Allocation failure stores 0 in *this.
**Calls:** Pool_AllocZero 0040db40.
**Edge cases:** the shared-pool path's failure branch writes through address 0x10 (a crash). Nodes are never freed back to the pool except through the list's own free list. The block holds capacity + 1 nodes and the bump pointer is not checked against it: inserting more than that overruns the block.
**Evidence:** export/0040f590.c, 0040f670-0040f870 for the field uses; callers 00402240/00402300 (to read).
**Port:** engines/tesoro/core/cursorlist.h::CursorList (codex/fresh-core, uncommitted), default constructor. Deviations: the list is a plain array with a cursor index (the node pool, free list and capacity are not modelled, so no overrun); a list built from a source does not share a pool.
**Validation:** the initial state (empty, data slot 0) is compared by the vectors; the rest of the contract is not exercised. See 0040f800 for the full description of the check.
**Open questions:** which lists share a pool and why (the callers).
