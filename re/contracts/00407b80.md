# 00407b80 — inferred_Jim_EnterLevel
Status: ported · Cluster: 29 · Convention: thiscall(Jim *this, Level *level, Room *rooms, int x, int y) — RET 0x10
**Behaviour (read, not ported; Jim is not ported):** if Jim is in a level: empty that level's moved list (+0x7c), remove Jim from its object list (0040f780) and from his room's list (00410530), remove that level from the main object list (0040fb20). Then: Jim's level (+0x40) := level, room (+0x3c) := rooms; append Jim to the new level's object list (0040f800), empty its moved list, insert him in the room (004104a0), move the new level's camera to Jim's OLD position without gliding (Level_CameraMoveTo 00408520), make the camera follow Jim (Camera_SetTarget 00402230), insert the level into the main list with priority 0x14, run 00408800 (the level's image reload, ported as the deferred load), load the deferred images of each of Jim's players (00401510) and apply the brightness table (00401010), then Jim's position := (x, y) with the target position the same, the hitter flag (0x400) := (the level's index != 8, the map), and move the camera to (x, y) again; finally Jim's slot 4 (update).
**Engine stand-in:** TesoroEngine::enterLevel makes the level current and puts its camera on (0, 0) (the second camera move, clamped to the level's bounds), without Jim; the menu levels have zero-height bounds so the camera ends on their frame.
**Port (31 Oct 2026):** `Jim::enterLevel` in `jimwalker.cpp`, same order as read above, using `Level`, `Room`, `Camera::setTarget` and the world for the main list and the archive stream. Brightness factor is the level's kind 1 object's `count` (+0x80). Deviation: a level without a kind 1 object skips the brightness step (the original reads through a null pointer). Checked by `re/tools/drivers/enterlevel_driver.cpp` (list membership, main-list calls, position, hitter flag, with a stub world); not compared against the original code, and the camera follow and image loads are not covered.
