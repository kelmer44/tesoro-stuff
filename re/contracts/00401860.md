# 00401860 — inferred_AnimPlayer_Advance
Status: emu-compared · Cluster: 1 · Depth: 1 · Convention: fastcall(AnimPlayer *this) — plain RET

**Purpose (confirmed):** Brings the play head up to the current game time and computes the object's movement offset for the sequence being shown.

**Inputs:** Clock_Now (global 00442120); this: +0x8 start time of the current sequence, +0xc cycle length (0 = none), +0x18 flags, +0x1c sequence array (0x24 bytes), +0x24 first, +0x26 last, +0x30 current sequence, +0x2c/+0x2e loop movement. Sequence fields: +4/+6 movement x, y (i16), +8 duration (u16).
**Outputs / state written:**
1. Only if flag 0 (playing) is set and flag 1 (paused) is clear: if +0xc != 0, now := now - ((u32)(now - start) / cycle) * cycle (whole cycles are dropped). Then while (int)(now - start) > duration(current): if flag 2 (loop) and current + 1 == last: start += duration, current := first, +0x2c += x(last) - x(first), +0x2e += y(last) - y(first) (16 bit wrap); otherwise, if current == last: clear flag 0 and stop; else start += duration, current += 1.
2. Output position (+0x28, +0x2a, i16): if current != last and flag 0: without flag 3, (+0x2c + x(current), +0x2e + y(current)); with flag 3 (interpolate), the movement runs from sequence current to current + 1 over duration(current): x = (x(next) - x(cur)) * t / duration + loopX + x(cur) with t = now - start (signed 32 bit multiply and IDIV, 16 bit result), same for y. Otherwise (stopped, paused, or at the last sequence): (x(current), y(current)) without the loop movement.
**Calls:** Clock_Now 00413a10.
**Yields / blocks / timing:** reads the clock once; no waiting.
**Edge cases:** a zero duration while interpolating divides by zero (crash); a loop whose sequences all last 0 ms never ends; the cycle division is unsigned, so a game time before the start gives a huge value; sequence indices are not range checked.
**Evidence:** asm 00401860-00401a4b read in full (compares: JLE at 004018d0 and JG at 00401963 are signed, DIV at 004018a1 is unsigned, IDIV at 004019d2/004019ed). Callers: Obj_AnimTick 00401c30, Obj_AnimTickResetOffset 00407770, 00407790, Jim_TalkAnimate 00407f30, 0040e6a0, 0040e890.
**Port:** engines/tesoro/core/animbank.cpp::AnimPlayer::advance (codex/fresh-core, uncommitted). Deviations: returns with a warning instead of reading outside the table, and does not interpolate a zero-duration sequence.
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_anim.py + drivers/anim_driver.cpp): original function run in Unicorn after Load + SetRange on synthetic banks with durations 1-400 (both interpolate and plain, looping and not, with and without summed duration, game times from 0 to 20 s ahead, pause/resume interleaved) vs engine AnimPlayer: advance 1131/1131, pause 276/276, resume 101/101. Six deliberate mutations of the port were caught. Not covered: zero-duration sequences (the original divides by zero when interpolating and can loop forever), game times before the start time, resume without a previous pause (the original reads an uninitialised field), ranges outside the sequence table.
**Open questions:** what the movement offset is added to (callers); why the stopped position ignores the loop movement.
**Audit/uses (29 Oct 2026):** Jim_TalkAnimate 00407f30 draws the current image at (sequence 0 x scaled + object x - camera + 0x140 + movementX, ... - movementY + 0xf0): the movement offset is added to the object's screen position, y pointing up. Floor-point evidence: 0040e890 walks the type 4 list (x, y at +0x20 stride 4, scale at +0x14 stride 2), see PLAN pending renames.
