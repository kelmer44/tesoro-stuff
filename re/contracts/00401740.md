# 00401740 — inferred_AnimPlayer_SetRange
Status: understood · Cluster: 1 · Depth: 1 · Convention: thiscall(AnimPlayer *this, uint16 first, int last, uint8 loop, char sum) — RET 0x10

**Purpose (confirmed):** Starts playing a range of sequence records: sets first/last record, flags, optional total duration, and stamps the start time.

**Inputs:** first (u16); last (int, -1 = find automatically, else truncated to u16); loop (bit 0 only is used); sum (nonzero: add up record durations). this: +0x18 flags, +0x1c record array (0x24 bytes per record), +0x22 record count.
**Record fields used (in memory, from AnimBank_Load):** +8 u16 duration, +0x18 pointer (image slot, 0 when the record has no image).
**Outputs / state written:**
- flags (+0x18): bits 1 and 2 cleared, bit 2 := loop, bit 0 (playing) := 1; other bits (bit 3) kept.
- +0x24 := first.
- record count == 0: +0x26, +0x24, +0x30 := 0, +0xc := 0, flags := 0 (every bit cleared).
- otherwise: last is -1: +0x26 := first; then while +0x26 + 1 < count: if record[+0x26 + 1] has image slot 0, stop (and, if loop, +0x26 += 1 so the slot-less record is included); else +0x26 += 1. last given: +0x26 := (u16)last.
  +0x30 := first; +0xc := 0; if sum and first <= +0x26: +0xc := sum of u16 durations of records first..+0x26 inclusive. If first == +0x26, bit 0 (playing) is cleared again (a single record range does not play).
- always: +0x2c := 0, +0x2e := 0, +0x8 := Clock_Now(global 00442120).
**Calls:** Clock_Now 00413a10 (understood).
**Yields / blocks / timing:** reads the game clock once.
**Edge cases:** the automatic search stops at the end of the table (+0x26 = count-1) when no slot-less record follows. Indices are not range checked (first >= count reads past the array in the sum loop: it is guarded by first <= +0x26 only). Decompiler shows the test as +0x3c of record n, which is +0x18 of record n+1.
**Evidence:** asm 00401740-00401856 (flag mask 0xf9, loop test CMP ...+0x3c, sum loop stride 0x24).
**Port:** engines/tesoro/core/animbank.cpp::AnimPlayer::setRange (the clock value is passed in). Deviation: a range reading past the sequence table is cut short with a warning.
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_anim.py + drivers/anim_driver.cpp): original Load/LoadImage/LoadDeferredImages/ScaleBrightness/SetRange run in Unicorn (fread/fgetpos/fseek/fsetpos, Archive_SeekEntry, the pool allocator and Clock_Now replaced by Python) on 700 synthetic animation files (0-9 sequences of types 0/1/2/4, 0-5 images of types 0/1/2/3/7, both pixel layouts, 5-5-5 and 5-6-5, load modes 0 and 2) vs engine AnimPlayer/AnimBank/AnimImage: load 700/700, header 700/700, flags 700/700, sequences 2509/2509, image positions 700/700, images after load 1396/1396, after deferred load 861/861, after brightness 832/832, SetRange 1748/1748. Five deliberate mutations of the port were all caught. Limits: synthetic data only (the shipped .DAT was not read); pool allocation/exhaustion is not modelled; the 5-5-5 overrun past the blob end and a sequence-less bank with images are not reproduced; pixel-first layouts are tested only without 5-5-5; item arrays shared by two spans are not tested; ranges reading past the sequence table are not tested.
**Open questions:** meaning of the slot-less record that ends a run. Resolved by AnimPlayer_Advance: +0x2c/+0x2e are the movement gathered by completed loops (loopX, loopY); +0x30 is the sequence being played; +0x24/+0x26 first/last.
