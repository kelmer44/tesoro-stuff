**Port (31 Oct 2026, superseded below):** `WalkFloor::onAttach`: the route lookup and the brightness 200 are ported; the borrowing of the other level's floor animation is **not** (it warns). Open: what the global at 004421d8 holds and who sets it (no code writer is in the exports).

**Port (5 Nov 2026):** the borrowing is ported. `WalkFloor::onAttach` asks `Level::sharedFloorLevel()` (the engine answers with level 42) for the floor named SUELO and takes over its animation players (`AnimSet::shareFrom`, a copy made at attach, where the original shares the live player: they differ only if a script changes the shared floor's frame, none seen). Level 42 itself returns none (it would borrow from itself). **Global 004421d8** is entry 42 of the level table (0x4421d8 - 0x442130 = 0xa8 = 4 x 42), which is `19.LVL` (the first numbered level is index 24); it has its own floor and brightness 201, the other labyrinth levels (23 to 43 except 34) borrow it. Not compared with the original code.
**Why it was missed (found by running the game, entrance level 23, track 15: Jim black and oversized):** not a missing decompilation. The function was decompiled and this contract listed the borrow as not ported. The bigger fault was wiring: `World::loadLevelFile` attached the level's objects before `World::level` set the level's index, so the index test above never passed and even the already ported brightness 200 never ran (Jim was scaled by the 1/256 of an unprepared level, and had no perspective scale). The index is now set before attaching.
