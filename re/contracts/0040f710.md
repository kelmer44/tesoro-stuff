# 0040f710 — inferred_ObjectList_ForEachAttach
Status: ported · Cluster: 27 · Convention: thiscall(List *this, Level *level) — RET 4

**Purpose (confirmed):** Rewinds the plain `List` (no priority) and calls Object_AttachToLevel (00401bf0) on every element, passing the level.
**Behaviour:** sets the at-start flag (L+0x14) and the cursor (L+0xc) to the head link (L+4), then repeats the cursor step inlined from the list code (same logic as 0040fe40 for the plain list): stop if the next link is empty; the first step keeps the cursor and clears the flag, later ones advance; the element is read into the value slot (L+0x18). Each element is attached before the next step, so the cursor and value slot are live while the attach (including its vtable slot 0) runs.
**Callers:** 00408540 Level_AttachObjects, on the list at level +0x74.
**Calls:** 00401bf0.
**Port:** attachAll() in core/object.cpp, built but not emulator-compared: the loop is `rewind(); while (step()) value()->attachToLevel(level);` on CursorList.
**Open questions:** whether any slot-0 override (kind 1 resolves the walk area by name in the level's list) changes this list while it is walked; the inlined step would then see the change.
