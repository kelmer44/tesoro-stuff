# 00406d50 — Kind 13 set verb and click (slot 14)
Status: emu-compared · Convention: thiscall
**Behaviour:** Stores the verb. A verb 0..6 with a line of its own: Jim says it (answer colour), pointer off, pending, main list at priority 5, returns 3. Without a line: verb 0 picks the item up (3); verbs 1..6 call the item's verb slot, returning 1 if it did something, else pick it up (3). A verb of 7 or more (an item used on this one): looks for a combination in this item's list that resolves to the carried item, then in the carried item's list for one that resolves to this item (the key is looked up in the interface level): Jim says its line, pointer off, pending, main list, the interface turns a page to the left, returns 3. Else the uses (this item's, then the carried item's) return 1 when they did something; else Jim says the stock line `MODELO2` (3).
**Port:** `InventoryItem::setVerbAndClick` (core/inventoryitem.cpp), with `ItemHost`.
**Validation:** `gen_vectors_items.py` + `drivers/items_driver.cpp`: 1,400 sessions over the 13 subtypes of kind 13 and three plain items (the original constructor with the factory's data tweak, state size and vtable, then update, pick-up, click with every verb and with items, the verb and use slots through the object's own vtable), 62,326 calls, 36,347 results and every field of the item, the carried item, the pointer, Jim's step bytes and the 8 fake objects identical. 41 mutations of the port, all caught except two equivalent ones (the high byte of a combination count that never exceeds 255, and a verb-6 line the constructor never sets).
