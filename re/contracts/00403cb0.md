# 00403cb0 — inferred_CdAudio_PlayTrack
Status: understood · Cluster: 8 · Convention: thiscall(CdAudio *this (the object at sound device +0x1c), byte track, byte flag) — RET 8
**Behaviour:** stops what plays (MCI command 0x808, if a device is open), clears +0x28; when track ≤ the number of tracks (+0x1bc) it sets time format "tracks" (0x80d with 0x400), and plays from `track` to track+1, or to the end when it is the last track (MCI play 0x806 with from/to); on success +0x29 := track and +0x28 := flag (the script passes 1; used as a "playing" flag for a later replay). A failed command closes the device (0x804). **Port:** not ported (ScummVM's audio CD manager plays a track by number; no CD audio files were read). **Open:** how the track numbers map to files without a CD.
