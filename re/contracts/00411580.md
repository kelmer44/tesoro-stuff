# 00411580 — Display_Raster_Mask (scaled shadow images, type 2 and any other type but 1 and 3)
Status: emu-compared · Cluster: 31 · Convention: 11 stack args (row table, row block, count, x16, row16, depth, clip, extra, scaleX, rowStep, shear), RET 0x2c
**Behaviour:** the same geometry as 00410fb0 (positions, scaled length, clipping, rows), but the stretches go into the **mask** list of each screen row (800 bytes per row), as 004112d0 does for unscaled shadows: +4 = extra (depth window), +0xe = the item's first u16 (the page of the shade table), +0xc = depth. Nothing is painted; the merge and the flush at compose time do the shading.
**Port (5 Nov 2026):** `RenderQueue::queueScaledRows` (shadow). **Validation:** same run as 00410fb0 (shadows scaled and unscaled, at most one per frame because overlapping shadows are undefined in the original): 426 frames identical; with the extra not passed the mutation was caught on 5 frames (a depth window is used by few scaled shadows in the vectors, 70 of 2,314 scaled sprites).
