# 004132b0 — inferred_Movie_Start
Status: understood · Cluster: 8 · Convention: fastcall(Display *this) with one stack argument (the movie number), RET 4
**Behaviour:** builds the path "%c:\INSTALL\BIN\DATA%02i.BIN" (drive letter of the game disc and the movie number, two digits: for example `D:\INSTALL\BIN\DATA01.BIN`; the file is not in the archive), starts COM, builds a DirectShow graph for that file and plays it full screen into the display; it loops until the movie ends or the first byte of the keyboard state (bit 0, the skip key) is set, polling input and presenting; then stops it, releases the graph, waits until the buttons are released (mouse byte & 0x3c) and sleeps 500 ms (0x4139e0). Returns true on success, false when any step fails (then the script simply goes on). **Port:** not ported; needs the movie files (format of *.BIN unread) from the original disc. **Open:** the container format.
