# 004132b0 — inferred_Movie_Start
Status: understood · Cluster: 8 · Convention: fastcall(Display *this) with one stack argument (the movie number), RET 4
**Behaviour:** builds the path "%c:\INSTALL\BIN\DATA%02i.BIN" (drive letter of the game disc and the movie number, two digits: for example `D:\INSTALL\BIN\DATA01.BIN`; the file is not in the archive), starts COM, builds a DirectShow graph for that file and plays it full screen into the display; it loops until the movie ends or the first byte of the keyboard state (bit 0, the skip key) is set, polling input and presenting; then stops it, releases the graph, waits until the buttons are released (mouse byte & 0x3c) and sleeps 500 ms (0x4139e0). Returns true on success, false when any step fails (then the script simply goes on). **Port (4 Nov):** `World::startMovie` (world.cpp): the files are plain AVI (RIFF AVI, 640x480, Intel Indeo 5.0 video, checked on data00 and data01 from the disc extraction), so ScummVM's `Video::AVIDecoder` plays them (the engine now needs the Indeo 4&5 component: `configure.engine`). It plays from `bin/dataNN.bin` next to the game files until the end or until Escape is let go (the original tests the first keyboard byte's bit 0, the "released this frame" state), then waits for the mouse buttons and 500 ms (`TesoroEngine::releaseInputAfterMovie`). Deviations: a missing file or a failed decode warns and the script goes on (the original also returns false then); the picture is shown centred in the 640x480 window rather than through DirectShow's own window. **Not compared or run:** playback has not been seen (builds only); audio goes through ScummVM's mixer.
**File facts (5 Nov 2026, media probe on all of `bin/data00.bin`..`data12.bin` of the disc extraction):** all 13 are AVI with Indeo 5 video, 640x480; 12 fps except data00, 05, 06, 08 (23.976 fps); PCM audio at 22,050 Hz in data00, 02, 08 (16-bit stereo), 12 (16-bit mono), 03 (8-bit mono) and 04 (8-bit stereo), no audio elsewhere; durations 1.0 s (data05) to 146.8 s (data02). Call sites: start-up (InitGameWorld pushes 0), a script's play-avi command (number from the entry) and the first arrival at place 16 (9). **Limits:** a headless engine run (dummy video/audio) printed no warning at start-up, but playback was not observed; the original's wait-for-completion call and the repeated surface blits in its loop were read only (their exact interface identity is unconfirmed); no comparison with the original runtime.
