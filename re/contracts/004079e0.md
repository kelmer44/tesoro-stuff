# 004079e0 — inferred_Jim_Slot12 (collision callback)
Status: understood in outline · Cluster: 29 · Convention: thiscall(Jim *this, Object *other) → 1 — vtable slot 12 (hitter.onTouched(other, extra))
**Behaviour (read, not ported):** only while walking (+0xd5): the target position (+0x54/+0x58) := the current one, out of the main list. If the walk was not direct and `other` (the level's kind 1 object, whose +0x78 is the walk area) has a walk area: the route is recomputed with 0x414f10 (FindPath: vertex route); when it returns false (no vertices) Jim faces his facing and the target is told (its slot 13) and 1 is returned; if it returns true Jim has been sent to the first vertex (direct walks) and the target is told when he gets to the end. Otherwise (a direct walk) the direct flag is cleared and Jim faces (slot 29) his facing. Slot 11 of Jim (0x4079d0) is "state byte +0x5c == 7", which makes him the hitter of the collision test only in that state. **Port:** not ported. **Open:** which object collides with Jim here, and when his state byte is 7 (inferred: the kind 1 object as `other`).
