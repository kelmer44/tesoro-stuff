# 004067a0 — inferred_ScriptBlock_CopyCtor
Status: understood · Cluster: 11 · Convention: thiscall(ScriptBlock *this, ScriptBlock *source)

**Purpose (confirmed):** Copies the 0xd8 bytes of a parsed block field by field into a new object (the class of types 0..0x11 is picked by the caller by setting the vtable afterwards). 0x404630 is the same copy for types 0x12..0x15. Nothing is transformed.
**Port:** not needed: ScriptBlock keeps the compiled data directly. The block *type* decides the vtable slot 0x70 ("DO" routine); only type 17 (0x417c80) is read so far.
