# 00411f20 — inferred_Display_ResetRenderQueue
Status: emu-compared · Cluster: 31 · Convention: fastcall(Display *this)

**Purpose (confirmed):** Empties the per-row span lists for a new frame. The display (global 00442108) owns two row arrays: +0x670 = 480 rows of 2000 bytes (the main queue, 125 span nodes of 16 bytes each, the first two being the row header) and +0x674 = 480 rows of 800 bytes (the second queue used by the mask/shadow images, 50 nodes). Row header: +0 first span, +0xc u16 next unused node (starts at 2), +0x10 free list.
**Outputs / state written:** every row header := {head 0, bump 2, free 0}; display +0x13a0 := 0 (count of queued texts/overlays), +0x664 := 0 (count of deferred scaled sprites), +0x668 := 0 (u16). The same code ends the display constructor and ClearAndReset (00412bb0).
**Port:** RenderQueue::reset (rows only; the counters belong to the parts not ported yet).
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_render.py + drivers/render_driver.cpp), see 004105a0.
