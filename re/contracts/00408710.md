# 00408710 — Level_LoadState
Status: understood · thiscall(Level *this, FILE *stream). Loop: read 8 bytes (one record of size 8, count 1) as a name key; stop when both words are zero. Find the object of that key in the level's list (ObjectList_FindByKey on +0x74). If found: read its flags (4 bytes into +0x68) and call its LoadState (slot 9). If NOT found: nothing more is read for that record, so the stream is then out of step (the following bytes are taken as the next key).
**Edge cases:** a short read (end of file) leaves the previous key in the buffer, so a truncated file keeps repeating the last key (the first non-matching key would not end the loop). Written flags overwrite all 32 bits of +0x68 (including the "processed", "active" and "collidable" bits).
**Port:** not ported. **Validation:** none.
**Open questions:** whether any shipped level has an object that is missing at load (e.g. built by the story after the save).
