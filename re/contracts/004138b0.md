# 004138b0 — inferred_SpeechTable_Find
Status: emu-compared · Cluster: 33 · Convention: thiscall(SpeechTable *this, uint32 keyLo, uint32 keyHi) returns Entry * (RET 8)

**Purpose (confirmed):** Binary search of the table for a key. The table is in descending order: lo = 0, hi = count - 1, mid = (lo + hi) >> 1; compare the key with the entry (low half, then high half, as differences); equal: return the entry (a pointer; a script keeps it as its phrase), key smaller: lo = mid + 1, else hi = mid - 1. Not found: 0.
**Port:** SpeechTable::find (returns the index, -1 when missing). **Validation:** see 00413570.
