# 00405630 — inferred_ScriptBlock_Resolve
Status: emu-compared · Cluster: 10 · Convention: fastcall(ScriptBlock *this)

**Purpose (confirmed):** Turns names into positions in one block, walking its entries in order:
- op 4 (jmp): [+4] := index of the label (key at +4/+8) in this block, 0 if none.
- op 7 (if): the same for the label; then the variable number and value move from [+0xc/+0xd] to [+8/+9].
- op 5 (menu): forget the previous item.
- op 6 (menu item): if an earlier item (index above 0, so never the item at index 0) is waiting, its [+4] short := this index; this item becomes the waiting one unless its own [+4] is 0 ('next' not given); its [+4] := 0xffff. So the items of one menu form a chain through the entries marked 'next'.
- op 8 (run): if the block key is FANMTRONO (key of 0x42d1f0) [+4] := 0, else [+4] := the block with that key from the global table (0x4060c0 logic, 0 if missing; a pointer in the original, index + 1 in the port); then [+8] := [+0xc] and [+0xc] := [+0x10] (the label key moves down).
**Port:** the loop body of ScriptLibrary::resolve. **Validation:** see 00404810.
**Data findings (30 Oct 2026, from the shipped texts):** three jumps name labels that do not exist (OBJETOS.DLG blocks FDICKCOCINA `ent2`, FORZOGUEI `curado`, FTIENDA `_hipnotiz`); they resolve to entry 0, as the original does. The 2,687 speech lines have no duplicate IDs across the four files and every spoken line a script names exists (agrees with the legacy notes).
