**Purpose (read in full):** Builds everything the game needs before the first frame, after InitSubsystems.
**Order of effects:** opens the archive (Tesoro.dat / Tesoro.TRE); loads TABLA1.TBL (colour table) into the display; loads the font bank FUENTES.ANM and gives it to the display; loads four text tables (OBJETOS.TXT, ANIMS.TXT, CONVERS.TXT, ICONS.TXT) into 00442110..0044211c; builds INTERFACE.LVL with Level_Load (mode 1) as a level of class 0042bc40 into 004421ec; builds the dialogue table (0x2b0 bytes) at 004420b8 and loads OBJETOS.DLG, ANIMS.DLG, CONVERS.DLG, ICONS.DLG into it, then finalises it; builds Jim (0x114 bytes, Jim_Ctor 004070c0) into 004420fc; inserts the interface level into the main object list (00442104) with priority 0x13; builds the top object (0x6c bytes, TopObject_Ctor 00415230) into 004421f8 and inserts it with priority 100; ObjectList_AttachAll; Level_AttachObjects on the interface level.
Then, for the 47 entries of the level table (names at 0042d6c8, 15-byte stride: DESPACHO, PUERTO, TABERNA, CUBIERTA, CAMAROTE, ALMACEN, COCINA, PLAYA, MAPA, POBLADO, PANTANO, CAMPAMENTO, VOLCAN, ARMARIO, TABLERO, TIERRA, RISCO, CUBIERTA2, CAMAROTE2, ALMACEN2, COCINA2, LUCHA, TRONO, ENTRADA, 1 to 20, RISCOFINAL, FINAL, CREDITOS, all .LVL): the pool arena 2 is reset, and a Level_Load (mode 2, deferred pictures) builds the level into 00442130 + 4 * index (a level of class 0042bbd0 for entry 3, 0042bc08 for entry 8 MAPA, the plain level class otherwise; empty names give no level), and the index is stored at level +0x98. Then PRINCIPAL.LVL (main menu) into 004421f0 and NUEVO.LVL (new-game menu) into 004421f4; every level gets Level_AttachObjects.
Finally some objects are switched off at the start by their name key: PUERTA1 of DESPACHO (hidden), BAULOPEN, CANOA, RISCO and CUEVA, DICK, SOGACORTADA, CAPIMUERTO, JIMCUBO (hidden and off), FERNAN (slot 8 SetActive(0), or SetVisible for the two hidden ones); Jim is switched off, enters PRINCIPAL.LVL (Jim_EnterLevel 00407b80 with the level's room array +0x70 and position (0,0)) and the intro movie starts (Movie_Start 004132b0).
