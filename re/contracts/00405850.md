# 00405850 — inferred_Script_Tick
Status: understood · Cluster: 10 · Convention: fastcall(ScriptBlock *this) — vtable slot 4 (per frame)

**Purpose (confirmed in outline):** What a running script does each frame. The entry at the program counter decides:
- 1 (spoken line): wait while the acting object is still speaking; once it stops, wait until 201 ms have passed since it ended (a timer kept in global 004420c8), then move on.
- 2 (sleep): wait until the time since the sleep started reaches [+4] ms, then move on.
- 5 / 6 (menu): the menu is shown once (the choice texts collected by 0x405a60, the cursor reset, 0x407d00 shows the list and returns the choice); when the choice window has closed, the program counter jumps to the position stored for the chosen item and the script goes on.
- 8 (run): switches Jim's input off and moves on.
- 9 (sendmessage): waits while the object's animation still runs (flag +0x18 bit 0) unless the entry asks not to.
- anything else: nothing to wait for.
When the program counter moved, the executor 0x405a60 runs the next steps at once, and its result (2 = still waiting, 3 = done this frame) is returned.
**Port:** not ported. **Open questions:** the exact conditions of 1 and 9 (the object fields read are named only by offset).
