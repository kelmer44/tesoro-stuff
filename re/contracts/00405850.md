# 00405850 — inferred_Script_Tick
Status: emu-compared · Cluster: 10 · Convention: fastcall(ScriptBlock *this) — vtable slot 4 (per frame)

**Purpose (confirmed):** What a running script does each frame. The entry at the program counter decides:
- 1 (spoken line): wait while the acting object is speaking (byte +0xd4); once it stops, remember the time (global 004420c8, if not set), and wait until 201 ms have passed since; then move on.
- 2 (sleep): wait until the time since the sleep started reaches [+4] ms, then move on.
- 5 / 6 (menu): the first time (flag 004420c0 clear): remember the cursor's picture frame (global 00442128 +0x38 → +0x30), make the object the cursor held visible again (flags +0x68 |= 4) and let go of it (+0x12c := 0), select the cursor's bank 0 (0x401de0), show the list (0x407d00 on Jim with the phrases and count) and keep the choice; if one was chosen: flag := 1, Jim is the acting object and says the chosen phrase (0x410330). While the flag is set and Jim has stopped speaking: restore the frame, pc := the stored resume position of the choice, run the executor, return 3.
- 8 (run): tells the cursor 0 (off) and moves on.
- 9 (sendmessage): only an animation order (0) waits, and only while the object's animation runs (object slot 0xc is called, then bit 0 of the flag at +0x38 → +0x18); the other orders (walk) wait for 0x406140.
- anything else: nothing to wait for and nothing changes (returns 2).
When the program counter moved, the executor 0x405a60 runs the next steps at once and its result is returned, else 2.
**Port:** `ScriptRunner::tick`, with `beginMenu`/`showMenu`/`endMenu` standing for the menu's cursor handling. Emu-compared (977 sessions). **Open questions:** what 0x407d00 draws and how it chooses.
