# 00419050 — Connect4_FindBestMoves
Status: emu-compared · Convention: cdecl
**Behaviour:** For each non-full column, drops a piece of the side, scores it and takes it back; keeps the columns with the best score (score in the out argument). Returns -1 if every column is full. Otherwise, for each candidate in order, drops the machine's piece and looks whether the player then has a column that wins at once; the first candidate that leaves none is returned. If all lose, a random one of the candidates (0x413b00).
**Port:** `ConnectFour::bestMove` (core/connectfour.cpp).
**Validation:** `gen_vectors_connect.py` + `drivers/connect_driver.cpp` (in `run_startup_check.sh`): 1,200 boards from random play (wins, near wins, full columns), 4,200 operations; result, the whole board, the cells of the last line, the search's score and every random-number call identical to the original run in Unicorn. 10 mutations of the port, all caught.
