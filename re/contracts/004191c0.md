# 004191c0 — Connect4_ChooseMove: the machine's turn
Status: emu-compared · Convention: cdecl
**Behaviour:** Returns 1 if the player's last piece (column given) made four. Else drops a machine piece in each column in turn: if one makes four it stays and 2 is returned. Else the best columns of each side are searched (the player's for blocking, the machine's own); no column left returns 3 (draw). The machine drops in the player's best column when its own score is not greater than the player's, else in its own. Returns 0.
**Port:** `ConnectFour::choose` (core/connectfour.cpp).
**Validation:** `gen_vectors_connect.py` + `drivers/connect_driver.cpp` (in `run_startup_check.sh`): 1,200 boards from random play (wins, near wins, full columns), 4,200 operations; result, the whole board, the cells of the last line, the search's score and every random-number call identical to the original run in Unicorn. 10 mutations of the port, all caught.
