# 00401aa0 — inferred_Object_AnimatedCtor (was Obj_Kind00_Ctor)
Status: emu-compared · Cluster: 1 · Convention: thiscall(Obj *this, Record *rec, RoomRecord *room, AnimPlayer **bankTable, int indexBase, ushort stateSize) — RET 0x14

**Purpose (confirmed):** Builds an object with animations from a level record: the constructor of kind 0 and the base of every kind that animates (Jim, items, doors, effects call it first).
**Inputs:** rec (level record): +0 i32 x, +4 i32 y, +8 i16 sort offset, +0xb u8 bank count, +0xc name (up to 12 chars), +0x18 u32 kind (used by the factory 00409e50), +0x1c pointer to the bank indices (indexBase is added to it); room record: +8 i16 sort offset; bankTable: array of AnimPlayer pointers of the level; stateSize.
**Outputs / state written:** vtable := 00428000; +0x5d := 0; flags |= 2 (active); +0x4c/+0x50 := rec x, y; +0x3c := room; +0x5e := rec.sort + room.sort + 5; +0x44 := NameKey64(rec.name); +0x33 := bank count; +0x34 := zeroed array of count pointers (pool arena 1); per bank i: a new 0x40-byte player (pool arena 1, constructor 00401000) copied from bankTable[indices[i]] by Copy64Bytes, flags |= 0x10 (has animation); +0x54/+0x58 := x, y; +0x38 := players[0]; +0x32 := 0; +0x64 := stateSize; +0x60 := zeroed blob of stateSize bytes (arena 1) or 0.
**Calls:** NameKey64 00415c40, Pool alloc zeroed 0040db40, Pool alloc 0040f650, ReturnThis 00401000, Copy64Bytes 00401580.
**Yields / blocks / timing:** none
**Edge cases:** allocation failures yield 0 pointers (player 0 is stored unchecked); a bank count of 0 leaves +0x38 pointing at the unset first array slot; bank indices are not range checked. The object is allocated zeroed by the factory 00409e50 before the call.
**Evidence:** asm 00401aa0-00401bb1 read in full (argument offsets checked against the stack layout; the call from 0040e5c0 passes the same five arguments).
**Port:** engines/tesoro/core/object.cpp::Object::initAnimated (+ AnimSet::init). Deviations: the room pointer, the state blob and byte +0x5d are not kept; the pool is replaced by the heap; a bank index outside the table gets an empty player and a warning.
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_anim.py + drivers/anim_driver.cpp): the original function run in Unicorn (pool allocations replaced; name hash, Copy64Bytes, AnimTick and the vtable at 00428000 run as in the executable) vs engine Object.
