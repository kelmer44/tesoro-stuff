# 00411f80 — inferred_Display_AddSprite
Status: emu-compared (literal and solid images) · Cluster: 31 · Convention: thiscall(Display *this, int x, int y, ushort depth, Image *image, uint extra) — RET 0x14

**Purpose (confirmed):** Queues an unscaled image for this frame's compose. Image fields: +8 u16 width, +0xa u16 height (rows), +0xc u16 type, +0x10 the row table (8 bytes per row: items pointer, u16 item count). Item (8 bytes): pixel pointer, u16 x offset from the end of the previous item, u16 length.
**Behaviour:** right = width − 1 + x, bottom = height − 1 + y. Nothing happens unless x < 640, right ≥ 0, y < 480, bottom ≥ 0. If y < 0 the first −y rows are skipped and y := 0; bottom is capped at 479; count = bottom − y + 1. The clip flag is x < 0 or right > 639. Then by type: 1 → QueueRow_Literal (004105a0) with the main queue row y (+0x670 + y·2000); 3 → 00410cc0 with the same queue; any other → 004112d0 with the mask queue (+0x674 + y·800) and `extra`.
**Port:** RenderQueue::addSprite; types 1 and 3 are queued, the mask type warns and is skipped.
**Validation:** see 004105a0 and 00410cc0.
**Open questions:** the mask type (004112d0) and the scaled path (004120c0 → 00412120 → raster functions).
