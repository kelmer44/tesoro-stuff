# 0040e890 — Kind16 animation tick (slot 2): wait, then travel along the anchor's path
Status: understood · fastcall(this). The path is a sequence of the anchor object's animation: its points (+0x20 of the sequence record: 4 bytes per point, x and y as i16), a per-point scale table (+0x14, u16 per point), point count (+0x1c). Fields: +0x74 time stamp, +0x78 wait, +0x88 anchor, +0x8e state (0 waiting, 1 travelling), +0x90 chosen path (sequence number in the anchor), +0x94 current point, +0x98 distance covered before the current point, +0x9c scale (0x100 = 1, reset to 0x100 every tick).
**Waiting (state 0):** the player's movement offset (+0x28, +0x2a) is zeroed. elapsed = Clock_Now − (stamp / 1000) — as compiled; the division is applied to the stamp, not to the difference. If elapsed − wait > 5: stamp := Clock_Now, wait := RandomRange(+0x6c, +0x70), return. If elapsed ≥ wait (so elapsed − wait in 0..5): start: distance := 0, state := 1, stamp := Clock_Now, point := 0, path := RandomRangeAlt(+0x8c, +0x8d), position := anchor position + the path's first point, then SelectAnimBank(this, 0, 0, −1, 1, 0) (start its own looping animation). If elapsed < wait: nothing.
**Travelling (state 1):** AnimPlayer_Advance(own player); travelled = (int) sqrt(offx² + offy²) of the player's movement offset. Segment length = (int) sqrt(dx² + dy²) between the current and next path point. While the covered distance + segment length ≤ travelled: if the current point is the second to last (count − 2 ≤ point) the trip ends: state := 0, position := anchor position + first point, wait := RandomRange(+0x6c, +0x70), stop; else point++, covered := the sum so far. While still travelling: the player's offset (+0x28, +0x2a) := the point-to-point linear interpolation (fraction (travelled − covered) / segment length) minus the path's first point, and scale +0x9c := the same interpolation between the per-point scale entries.
**Port:** not ported. **Validation:** none.
**Open questions:** the elapsed/stamp expression looks like a mistake of the original (a 6 ms window opens when the clock passes the wait); the effect on how often it starts is not measured; the units of RandomRange here; what a path of 0 or 1 points does (count − 2 negative).
