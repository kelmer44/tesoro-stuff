# 00416800 — inferred_DeckLevel_PicturesReloaded (vtable 0042bbd0 slot 13)
Status: ported · Cluster: 39 · Convention: fastcall(Level *this) · returns 1, or 3 when the mutiny scene was started

**Purpose (confirmed):** the ship's deck (level 3, class 0042bbd0) replaces the base "pictures reloaded" step (slot 13, 00408840) to add story events. It runs when the level's one-shot flag (+0x94, set by the deferred picture reload when Jim enters) is up: Level update 004087a0 clears it and tail-calls this.
**Behaviour:** (1) the base step: the music track of Jim's level (kind 1 object +0x7d) starts if non-zero, then the level's own step runs (the collision pass). (2) If Jim's story step (+0x111) is non-zero and this level's own kind 1 object's +0x7d is 8, it becomes 9 and track 9 starts. (3) If the step, as a signed byte, is above 2: starts the script block FANMOTIN at label `main` in Jim's level with the variable bytes pointing at the step (a byte on this function's stack in the original), then step += 1, Jim +0x110 := 1, returns 3. (4) Else if the step is 0: the object PESCADOR of the deck (level 3) has its state byte 0 changed from 2 to 3. Returns 1.
**Other levels:** the base class's slot 13 does only (1); the map class replaces it with 004179b0.
**Port:** `WorldLevel::picturesReloaded` / `deckEvents` (world.cpp) over `Level::picturesReloaded` (core/level.cpp, default: just the level's step). Deviations: the script variable byte lives in the level object (the original's stack byte is dead once the function returns); PESCADOR is looked up once, not twice (the lookup has no side effect).
**Validation:** `re/tools/check_deck_events.py`: the original in Unicorn with the callees replaced by logging stubs, 600 cases of step (including signed wrap values), track byte, fisherman state: calls, order, arguments, return value and every byte written match the contract's model (two mutations caught). The C++ is reviewed against the same model, not run against the original.
**Open questions:** what +0x110 (here called phase) and the fisherman's state 2 → 3 mean in the story; the FANMOTIN script's use of its variable bytes.
