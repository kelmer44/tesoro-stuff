# 00418d20 — Connect4_ScoreMove: the longest line a column's last piece makes
Status: emu-compared · Convention: cdecl
**Behaviour:** Board layout: byte 0 the column played last, then 8 bytes per column (count, 7 cells; 1 the player's piece, 2 the machine's). For each of four directions ((0,1), (1,1), (1,0), (1,-1) as column step and row step): walks back from the column's top piece while the cells are the side's, then forward counting and noting each cell as a (column, row) pair in a global table (0x442238...). Returns the longest, 4 as soon as one reaches four. Counts outside the columns read as zero.
**Port:** `ConnectFour::score` (core/connectfour.cpp).
**Validation:** `gen_vectors_connect.py` + `drivers/connect_driver.cpp` (in `run_startup_check.sh`): 1,200 boards from random play (wins, near wins, full columns), 4,200 operations; result, the whole board, the cells of the last line, the search's score and every random-number call identical to the original run in Unicorn. 10 mutations of the port, all caught.
