# 0040f680 — inferred_ObjectList_FindByKey
Status: ported · Cluster: 27 · Convention: thiscall(List *this, u32 keyLow, u32 keyHigh) — RET 8

**Purpose (confirmed):** Finds the object in a List whose name key (object +0x44 / +0x48) equals the 64 bit key. Walks a local copy of the list header, so the list's own cursor is not disturbed. Returns the object or 0.
**Port:** CursorList::findIf with a predicate on Object::nameKey. **Validation:** none (predicate search; the walk itself is validated through the other functions).
**Open questions:** none
