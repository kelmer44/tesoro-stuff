# 00410330 — inferred_Player_Say
Status: understood · Cluster: 10 · Convention: thiscall(Speaker *this, Line *line, int colour, int pose) — RET 0xc

**Purpose (confirmed):** Starts a spoken line on an object that can talk: the script characters (kind 5, 0xd8 bytes) and Jim. `line` is the 16-byte entry of a speech table (+8 archive offset of ID.WAV or 0, +0xc text).
**Writes:** +0xcc := colour argument (script lines of Jim (0x407ce0) pass minus his colour u16 at +0x100, so ≤ 0; verb answers (0x40f210 and the other defaults) pass Jim's u16 +0xd0, positive; other characters pass their text colour u16 at +0xd0); +0xc4 := line; +0xd4 := 1 (speaking); if +0xc (animation held) is 0: +0xc := 1, pause the current animation player (0x401a50) and stash bank and flags (0x401da0); +0xc8 := sound id from 0x404110(sound device 00442080, line+8, 0, 0, 0) or 0 when the line has no voice file; +0xa8 := clock now (talk animation timer); calls vtable slot 0x78 with `pose` (kind 5: 0x410130 SetPoseAnim, which also places the subtitle anchor; Jim: 0x408030, argument unused); inserts the object into the main list with priority 6 (0x40f900); calls vtable slot 4 (the update) once; returns 1.
**Callers:** 0x405a60 (say command, pose = the third number of the command), 0x407ce0 (Jim), 0x405850 (menu choice, pose 0), the verb handlers 0x40f210/0x40f280/0x40f300/0x40f380/0x40f400/0x40f480 (default phrases), 0x406d50.
**Port:** `Speaker::say` (core/speaker.cpp). Compared with the original on fake objects, callees hooked (voice, list, pose, animation), see gen_vectors_speaker.py: 800 sessions, 17,963 operations, 23,546 calls identical; 22 of 23 mutations caught (the survivor needs a speaking object without a line, which the port cannot reach). Script host `say(actor, phrase, extra)` is this call. **Open:** nothing read about +0xb0 table beyond SetPoseAnim.
