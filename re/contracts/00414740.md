# 00414740 — inferred_WalkArea_ScaleAt
Status: understood · thiscall(WalkArea *this, int x, int y) → int scale (0x100 = full size)
**Behaviour (read, not ported):** the perspective scale at a point from the polyline: for each segment (consecutive points of the current sequence, with a scale per point at record +0x14) whose x range contains x, the y of the segment at x is found; the first two such segments (one above and one below the point) are interpolated vertically between their scales (the scale at x on each segment is interpolated along it first); a point not between two segments gets the scale of the single segment found, and 0x100 when none is found. Integer divisions truncate toward zero. **Port:** not ported (the walk area is not ported).
