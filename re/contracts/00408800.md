# 00408800 — inferred_Level_ReloadDeferredAnims
Status: ported · Cluster: 13 · Convention: fastcall(Level *this)

**Purpose (confirmed):** Rewinds pool arena 2 (where deferred images were allocated), loads the deferred images of every bank (AnimBank_LoadDeferredImages 00401510, which does nothing for banks not loaded in mode 2) and sets the flag byte at +0x94, which makes the next Update call slot 13 instead of the collision pass.
**Port:** Level::reloadDeferredAnims (heap instead of the arena; takes the stream). Uses the bank loader that was emulator-compared; the level function itself is not compared.
