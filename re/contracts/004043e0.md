# 004043e0 — inferred_Sound_StreamRefill
Status: understood in outline · fastcall(Record *this) → true while the record plays
**Behaviour (read, not exact):** if the buffer reports a lost/invalid state (slot 0x10) it stops and returns false; when the whole data fits in the first buffer it stops once the play position passes the data end; otherwise, each time the play cursor (slot 0x24) crosses into the other half it reads the next 0x2b11 bytes of the archive file (0x41b4c0) into that half (slot 0x2c lock, 0x4c unlock), padding with 0x7f past the end of the data and finishing when the cursor passes the padded end. **Port:** not ported; any mixer-based playback with a finished flag is equivalent.
