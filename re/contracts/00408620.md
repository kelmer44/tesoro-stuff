# 00408620 — Level_SaveState
Status: understood · thiscall(Level *this, FILE *stream). Walks a copy of the level's object list header (+0x74) from the first to the last element. For every object except Jim (global 004420fc): writes its 64-bit name key (+0x44, 8 bytes), its flags (+0x68, 4 bytes), then calls the object's SaveState (slot 10, Obj_SaveState and its overrides). After the last object writes eight zero bytes (the end marker). The walk uses the list's own element order; it does not touch the level's own state (the caller saves that first through the level's slot 10).
**Port:** not ported. **Validation:** none.
**Open questions:** objects with equal name keys are both written; the loader finds only the first of them.
