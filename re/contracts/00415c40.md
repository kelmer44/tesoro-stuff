# 00415c40 — inferred_NameHash64
Status: understood · Cluster: 38 · Depth: 0 · Convention: cdecl(const char *name) returns uint64 in EDX:EAX

**Purpose (confirmed unless marked inferred):** Name hash used as the key of objects, scripts, phrases and levels: packs up to 12 characters, 5 bits each, into a 64-bit key.

**Inputs:** name (NUL terminated; characters compared as signed bytes against '5' (0x35)).
**Outputs / state written:** Low dword: first 6 characters; high dword: characters 7-12. Each char c contributes ((c < 0x35 (signed) ? c + 11 : c) & 0x1f); the value is accumulated by shifting left 5. A name shorter than a half is left-justified: after a NUL at index i the accumulated half is shifted left by 5 then by (25 - 5*i) & 31 for the low half, (55 - 5*i) & 31 for the high half. Characters beyond 12 are ignored. A name of exactly 12 characters needs no padding.
**Calls:** none
**Yields / blocks / timing:** none
**Edge cases:** Signed char compare means bytes >= 0x80 take the +11 path; only the low 5 bits survive, so different names can collide (e.g. letters differing by 32 map together).
