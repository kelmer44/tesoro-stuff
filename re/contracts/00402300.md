# 00402300 — inferred_Obj_Kind10_Ctor (object kind 10, the main pointer)
Status: ported · Cluster: 5 · Convention: thiscall(Obj *this, Record *rec, RoomRecord *room, AnimPlayer **bankTable, byte *data) — RET 0x10 · size 0x130

**Purpose (confirmed):** Builds the main mouse pointer: the kind 3 constructor (0040e5c0, so its data starts one animation run), vtable 00428038, label byte +0x78 := 0, two lists of capacity 0x1e (+0x6c hovered, +0x70 touched), the plain companion pointer (00402240, +0x74), sort value := 0, and flag bit 3 (collidable). It also changes the mouse (global 0044206c): range x from −320 to 319 (0xfffffec0..0x13f), y from −240 to 239 (0xffffff10..0xef), MouseCenter (00403a70), button timings 200 ms and 20000 ms (SetTimings 004036e0). So the pointer's mouse coordinates are measured from the middle of the window with y down.
**Port:** Cursor::initMain (core/cursor.cpp: SpriteObject::init + the pointer parts + companion) and Cursor::configureMouse (the mouse changes, applied by the host because the engine's mouse is not a global). Level::createObject builds kind 10.
**Validation:** the kind 3 part is the validated SpriteObject; the rest was checked by reading and by the drawn result. The shared hover list is a static of the engine class.
**Open questions:** where the pointer's hitter flag (0x400, which Cursor_IsHitter 00402e50 returns) is set: static reading finds no writer for pointers (Jim's constructor sets 0x41e, the mid base 0x508, kind 9 sets 0x400, Jim_EnterLevel sets it from the level index). Without it no object is ever touched by the pointer, so some code path outside the cursor functions must set it. See SUBSYSTEMS.md.
