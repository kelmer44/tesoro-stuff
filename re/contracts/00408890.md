# 00408890 — inferred_Level_CollisionPass
Status: emu-compared (shape-less objects) · Cluster: 13 · Convention: fastcall(Level *this)

**Purpose (confirmed):** The level's collision pass, run in the first pass of every frame when the level has no pending reload verb (Level_UpdateOrCollide, slot 4).
**Behaviour:** now = game clock.
1. Clear the touch list (level +0x78, 0x34-byte list, capacity 0x32).
2. For each object of the moved list (+0x7c): UpdateBounds (slot 3), then set its processed flag (bit 0).
3. For each moved object, for each object of its room's list that is collidable (8), active (2) and not processed: UpdateBounds. These are not marked, so such an object is updated again for every moved object in the room.
4. Clear the processed flag of the moved objects.
5. For each moved object that is collidable: for each other object in its room's list that is collidable and active: if the moved object IsHitter(other) (slot 11): ResolveOverlap(moved, other); else if other IsHitter(moved): ResolveOverlap(other, moved).
6. For each touch in the list, in order: hitter.OnTouched(other, time) (slot 12).
7. Clear the touch list; set every moved object's position (+0x4c/+0x50) back to its previous position (+0x54/+0x58); empty the moved list; level +0x8c := now.
**Calls:** 00413a10, slots 3, 11, 12, 00408c50.
**Port:** Level::collisionPass (core/level.cpp) with the touch list as an array. Level::update (slot 4) calls it with the frame time; after a deferred reload it only warns (the verb is not ported).
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_collide.py + drivers/collide_driver.cpp): synthetic levels built by the original Level_Load and attach (1-3 rooms, 1-6 kind 0 objects each), objects given a fake vtable whose slots 3, 11, 12 are Python hooks that log their calls and answer from a random table; random hit rectangles, moved areas, positions, sort values, flags (collidable, active, processed), moved lists and an optional player object, 1-3 passes per level: 590 passes, the call sequence (including 941 touches in their order) and the final positions, flags, moved-list size and +0x8c all identical. 13 mutations of the port caught. Not covered: objects with shape entries (see 00408c50), bounds computed by the real UpdateBounds (stubbed), a full touch pool.
**Open questions:** who fills the moved list besides ObjectMoved callers (Jim and moving objects, not read); why the pass restores the previous position.
