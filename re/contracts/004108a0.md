# 004108a0 — inferred_Display_Raster_Literal (scaled literal image rows)
Status: emu-compared · Cluster: 30 · Convention: thiscall(Display *this, rowTable, rowBlock, short count, int x16, int row16, ushort depth, char clip, int scaleX, int rowStep, int shear, uint y) — RET 0x2c

**Purpose (confirmed):** Paints `count` rows of a literal image straight into the frame (display +0x678, 1280 bytes per row) with horizontal scale, and enters what it painted in the row span lists.
**Per row:** the source row is row16 >> 16 (row16 += rowStep afterwards). For each item (the same RLE as the queued path, positions measured in source pixels from the end of the previous item): start = (source x · scaleX), screen xs = (start >> 16) + x, xe = ((end · scaleX − 0x7fff) >> 16) + x; the first source pixel is chosen by the sub-pixel offset −(frac8(start) · (inverse >> 8)), and when that is not 0, xs += 1 and the offset gains one step. inverse = 0x1000000 / (scaleX >> 8) is the source step per screen pixel. With clip: items wholly left of 0 are skipped, one starting left of 0 is cut (offset −= xs · inverse), one starting past 639 ends the row, xe is capped at 639. Pixels: dst[i] = source[(offset + i·inverse) >> 16]. Then the span xs..xe is inserted into the row list like QueueRow (004105a0) but marked as drawn: the piece cut off in front of an existing nearer span gets no pixels, and the final span gets pixels only when scaleX is exactly 0x10000 (a pointer to the source, so the row flush copies the same pixels again), otherwise "none".
**Edge cases:** scaleX >> 8 == 0 faults (the port warns); an image with height 1 under RasterRow divides by zero.
**Port:** RenderQueue::rasterRows (+ Row::insert with the drawn flag).
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_compose.py + drivers/compose_driver.cpp): original Compose with scaled images queued by 004120c0 (literal images with up to 70-pixel items and random pixel data, scales x 0.25-3, y 0.25-3 and upside down by 1 or 2, depths 0-5 and 65535 against a layer depth of 0, 1, 2 or 4, off every screen edge, 60% clustered so they overlap each other and the queued sprites): 614/614 composed frames, 294720/294720 rows identical. Mutations caught: row step, sub-pixel step, source pointer of unscaled spans, draw order of equal depths, layer test; not distinguishable: the −0x7fff rounding constant (0x8000 gives the same). Not covered: shear, solid and shadow images under scaling, images of height 1.
