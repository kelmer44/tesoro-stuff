**Behaviour (read, not ported):** the first-pass step of a clickable object. If its pending byte (+0x8c) is set and the cursor's flag (+0xd4 of global 004420fc) is clear: tell the cursor object (global 00442128, vtable slot 8) 1, clear +0x8c, remove the object from the main list (0040fb20 on global 00442104), then if +0x8d is clear dispatch on +0x9c (0..6 → slots 20, 21, 23, 22, 24, 25, 26; anything else: restore the visible bit of the cursor's held object (+0x12c), clear it, SelectBank(cursor,0,0,0,0,0), slot 27 with +0x9c − 7); if +0x8d is set clear it, run updateBounds (slot 3) and return 1. Otherwise (nothing pending) run updateBounds and return 1.
