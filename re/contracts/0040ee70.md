# 0040ee70 — interactive object update (vtable slot 4)
Status: emu-compared · Convention: fastcall(Obj *this) → int
**Behaviour:** when a click is pending (+0x8c) and Jim is not held (byte +0xd4 of Jim): the pointer is switched on, pending cleared, the object leaves the main list. If the click was not yet answered (+0x8d clear) the verb runs (0..6 to the verb handlers, anything else is an inventory item: the carried item is put back and slot 27 gets verb − 7) and its result is returned. If it was answered the flag is cleared and the object falls through to updateBounds and returns 1. Nothing pending: updateBounds, return 1.
**Port:** `InteractiveObject::update`.
