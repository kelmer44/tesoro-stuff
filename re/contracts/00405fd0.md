# 00405fd0 — inferred_Script_Start
Status: understood · Cluster: 10 · Convention: thiscall(ScriptBlock *this, uint32 labelLo, uint32 labelHi, byte *variables, Level *level) — RET 10

**Purpose (confirmed):** Starts a script block at a label. Clears the per-character object cache (this+0xb0, one entry per header character), resolves every character name to an object of `level` (0x408780), sets the menu positions (+0xa0/+0xa4) to -1, looks the label up (+0xc4 table, 12 bytes each; position 0 if missing) into the program counter (+0xcc), keeps the level (+0x40) and the variable array (+0xd0), clears the busy byte (+0x8c), inserts the block into the main object list with priority 0x1e (0x40fa10), switches Jim's input off (his vtable slot 8 with 0) and runs the first step (0x405a60). Returns 3.
**Callers:** 0x405a60 (`run`), 0x417b40 (menu clicks), 0x414560.
**Port:** not ported.
**Open questions:** Whether the label lookup fails silently (program counter 0) for a missing label in the shipped data.
