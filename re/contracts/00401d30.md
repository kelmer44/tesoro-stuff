# 00401d30 — inferred_Obj_SetPosition
Status: understood · Cluster: 1 · Convention: thiscall(Obj *this, int x, int y, char setCurrent) — RET 0xc

**Purpose (confirmed):** Moves an object. With setCurrent != 0 the current position (+0x4c/+0x50) is set too; the previous/target position (+0x54/+0x58) is always set. Then tells the level (+0x40) via 00408440 that the object moved (the level re-sorts its object lists when the object is collidable, flag bit 3).
**Calls:** Level_ObjectMoved 00408440 (a pooled linked list; not read).
**Port:** not yet (needs the level's object lists). `Object::setPosition` only stores the values.
**Open questions:** the list structure.
