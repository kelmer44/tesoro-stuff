# 00413ac0 — inferred_RandomRangeAlt
Status: understood · Cluster: 34 · Depth: 0 · Convention: stdcall(int min, int max) returns int (RET 8)

**Purpose (confirmed):** the game's second time-driven random function: like RandomRange but with a 7-bit fraction, with a different bit order.

**Inputs:** min, max (signed 32-bit); GetTickCount().
**Outputs / state written:** with t = tick: f = (t & 0x78) | ((t >> 7) & 7) | ((t & 7) << 7) (a 10-bit value: bits 3-6 of the tick stay in place, bits 7-9 move to bits 0-2 and bits 0-2 move to bits 7-9); result = ((f * (max - min + 1)) >> 10) + min in signed 32-bit arithmetic.
**Calls:** GetTickCount.
**Yields / blocks / timing:** time dependent, no state.
**Edge cases:** max < min gives a non-positive range factor; arithmetic shift; bits 10 and above of the tick are ignored, and the fraction uses 10 bits of the tick (bit 3-6 unchanged, the two outer 3-bit groups swapped), so it has up to 1024 values, not 128 (the earlier description 'seven bits' referred to the masks 0x78 and 7).
**Evidence:** disassembly 00413ac0-00413af0 (AND 0x78, SAR 7 / AND 7, SHL 7, IMUL, SAR 10, ADD min, RET 8); callers: Obj subtype classes (animation random).
