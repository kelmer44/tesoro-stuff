# 00415b00 — inferred_FindCdAndSetup
Status: understood · Cluster: 38 · Depth: 10 · Convention: cdecl(char uninstall) returns bool in AL

**Purpose (confirmed unless marked inferred):** Finds the game CD: enumerates logical drives, skips floppy-type drives (type 2), reads the volume label and compares it with `TESORO`; on a match sets the current directory to the drive root and starts `SETUP.EXE` through the exec wrapper (installer / uninstaller).

**Inputs:** param_1 (char): 0 = installer flow, 1 = uninstall flow (both branches call the same exec; the flag is not used otherwise in this function).
**Outputs / state written:** Returns 1 when a drive labelled TESORO was found (after the exec call, whose result is ignored); 0 when no drive matched. Side effects: SetCurrentDirectoryA(root), process launch.
**Calls:** GetLogicalDriveStringsA(0x104), GetDriveTypeA, GetVolumeInformationA, SetCurrentDirectoryA, exec wrapper 0041c3b0 (`SETUP.EXE`).
**Yields / blocks / timing:** Blocks only inside the exec call; no timing.
**Edge cases:** Drive type 2 (removable/floppy) is skipped; label compare is case-sensitive and exact; the string table is NUL-separated and the walk stops at the empty string. Exec result ignored.
**Evidence:** Decompile 00415b00, strings 0042e47c (`SETUP.EXE`), 0042e49c (`TESORO`); caller WinMain.
**Port:** not ported yet (no engine code written in the restart); a ScummVM port does not need the launcher at all (platform glue, replaced)
**Validation:** None.
**Open questions:** Whether SETUP.EXE accepts arguments from this call (none are passed).
