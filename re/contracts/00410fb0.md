# 00410fb0 — Display_Raster_Solid (scaled solid colour images, type 3)
Status: emu-compared · Cluster: 31 · Convention: thiscall-like, 10 stack args (row table, row block, count, x16, row16, depth, clip, scaleX, rowStep, shear), RET 0x28
**Behaviour:** paints **nothing**. For each of `count` rows it takes the source row row16 >> 16 (row16 += rowStep) and enters the solid stretches into the main row list of the screen row (pixels = 1, colour = the item's first u16, as 00410cc0 does for unscaled images). Per item: sourceX += the gap; xs = (sourceX · scaleX >> 16) + (x16 >> 16); xe = (length · scaleX >> 16) + xs − 1 (so a short item can be empty); sourceX += length. With clip: xe < 0 skips the item, xs < 0 becomes 0, xs > 639 ends the row, xe > 639 becomes 639. After each row x16 += shear (the known flaw: the 16.16 slope is added to a whole pixel position; the game passes 0). The insertion is the same as the unscaled solid one.
**Consequence kept:** in `Display_Compose` an image drawn after the rows are laid down (depth not deeper than the layer depth) has no visible effect.
