# 00403700 — inferred_InputDevice_UpdateStates (was Keyboard_UpdateKeyStates)
Status: emu-compared · Cluster: 6 · Convention: thiscall(Device *this, byte *raw, int count)

**Purpose (confirmed):** Turns the raw "is down" readings of a row of keys or buttons (raw byte 4 = down, else up) into the per-item states the game reads, and stamps the time of each change. Shared by the keyboard (00403980's base 004035b0) and the mouse. Device fields: +0xc release delay, +0x10 repeat delay (SetTimings 004036e0; the mouse sets 300 and 500), +0x14 array of u32 stamps, +0x1c array of state bytes.
**States (bytes):** 0 up · 8 pressed this frame · 4 held · 0x20 held past the repeat delay · 1 released this frame · 2 releasing (kept for the release delay) · 0x10 pressed again while releasing.
**Transitions, down:** 0 → 8 (stamp = GetTickCount); 8 or 0x10 → 4; 2 → 0x10; 4 and repeat delay < now − stamp → 0x20; others unchanged (1 stays 1, 0x20 stays 0x20).
**Transitions, up:** 1 → 2; 2 and release delay < now − stamp → 0; any state above 3 (4, 8, 0x10, 0x20) → 1 with stamp = now; 0 and an unelapsed 2 stay. Time differences are unsigned 32-bit.
**Calls:** GetTickCount (host tick).
**Port:** engines/tesoro/core/inputstate.cpp::InputStates::update (the tick is passed in).
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_input.py + drivers/input_driver.cpp): original run in Unicorn (GetTickCount replaced) on 400 fake devices of 1-4 items with random initial states (including unused values), delays 0 to 2^31 and tick steps around both delays and across 32-bit wrap, 2-40 updates each: 8722/8722 updates identical (states and stamps). 6 mutations caught (both comparisons, repress state, the > 3 test, stamping on release, the release → up step).
