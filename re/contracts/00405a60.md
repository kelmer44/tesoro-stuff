# 00405a60 — inferred_Script_Execute
Status: understood · Cluster: 10 · Convention: fastcall(ScriptBlock *this) returns 2 (waiting) or 3 (finished this frame)

**Purpose (confirmed in outline):** The script interpreter: runs entries from the program counter (+0xcc) until one has to wait. State: acting object (+0xac), per-character object cache (+0xb0), program counter, menu return position (+0xa0), variables (+0xd0, a byte array shared by the whole game), sleep start (+0xa8), level (+0x40).
- 0 and 10: end the script: take it out of the main object list (0x40fb20), switch Jim's input back on (slot 8 with 1), reset every cached character object whose busy byte (+0xc) is set (0x401dc0, 0x401a70), return 3.
- 1 say: character index in [+8] (0 = Jim): lazily resolve the object, start the phrase [+4] on it (0x410330 with its voice number at +0xd0 and [+0xc]; Jim: 0x407ce0); return 3.
- 2 sleep: remember the time, return 2.
- 3 break: with no menu on screen, end like 0; else jump back to the menu start (+0xa0).
- 4 jmp: program counter := [+4]. 7 if: variable[ [+8] ] == [+9] → program counter := [+4], else next. 0xb set: variable[ [+4] ] := [+5].
- 5 menu: remember the menu start, collect the choices (menu items whose condition variable allows, each with its phrase text from the line after it and the resume position two entries on), follow the 'next' chain; at the end Jim is the acting object and the executor returns 3 so the tick shows the list.
- 8 run: with a block (resolved by 0x405630) start it with the same variables and level (0x405fd0) and return 3; without (the FANMTRONO special) the label 'ir' selects 0x419f10(this, 0), any other label 0x419f10(this, 1) (the throne scene), then next.
- 9 sendmessage: the object is looked up by name in the entry's level (0 = the script's level) with 0x408780 (character digits use the cache). Orders: 0 animation (0x401de0 with first frame, last frame, loop/stop; word 3 = wait: return 3), 1 walk to x,y (object slot 0x80 with this script as the notification target; return 3), 2 look (slot 0x74), 3 activate (slot 8), 4 show (0x401d80 = visible flag).
- 0xc DO: calls the block's vtable slot 0x70 with the ordinal; next.
- 0xd play video: one display call (0x4132b0), the number in [+4] is not used by it; next. 0xe play sound: builds "NAME.WAV", looks it up in the archive (0x403500) and plays it (0x404110). 0xf play track: 0x403cb0(sound, track, 1).
**Port:** not ported (the compiled entries are ported: ScriptBlock). **Open questions:** the sounds, video and level calls (0x4132b0, 0x404110, 0x403cb0, 0x419f10, 0x407d00) are unread; 0x408780 (object by name in a level) is only partly known.
