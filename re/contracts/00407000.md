# 00407000 — Kind 13 slot 8: pick up / put back (setActive)
Status: emu-compared · Convention: thiscall
**Behaviour:** Put back (false): if this item is the carried one, the pointer shows its plain frame, the item is visible again and nothing is carried. Pick up (true): if the interface page is scrolled past 0x280, the previously carried item is made visible and this one hidden; this item is carried and the pointer shows frame number + 7. The active flag follows the argument.
**Port:** `InventoryItem::setActive` (core/inventoryitem.cpp), with `ItemHost`.
