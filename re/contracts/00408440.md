# 00408440 — inferred_Level_ObjectMoved
Status: emu-compared · Cluster: 13 · Convention: thiscall(Level *this, Object *obj) — RET 4

**Purpose (confirmed):** Makes sure a collidable object is in the level's list of objects the collision pass looks at.
**Behaviour:** if the object's collidable flag (8) is clear, nothing. Otherwise walk the list at +0x7c; if the object is already there, return; if not, append it at the end (the same step as 0040f800).
**Calls:** none (inlined list walk and insert).
**Port:** Level::objectMoved (core/level.cpp), the list is Level::movedObjects().
**Validation:** see 004080e0 (403 sequences, with flags toggled).
**Open questions:** who calls it (objects after they move; callers not read yet) and when entries leave the list.
