# 004079d0 — Jim's IsHitter (vtable 00428b70 slot 11) — formerly "Jim_IsInPose7"
Status: ported · Convention: thiscall(Jim *this, Object *other) — only the argument is used.

**Purpose (confirmed, corrected 4 Nov):** Jim is the hitter against any object whose kind byte (+0x5c) is 7, the walk floor: `return other->+0x5c == 7`. The earlier reading took +0x5c for one of Jim's own fields and the first port tested a Jim state byte instead, so Jim never collided with the floor and walked anywhere.
**Port:** `Jim::isHitter` (core/jimwalker.h): `other->kindId() == 7`. **Validation:** found by running the engine headless with scripted clicks (Jim then touches the floor at its edge); the function itself is one comparison, read from the decompile.
