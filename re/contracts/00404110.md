# 00404110 — inferred_Sound_PlayWav
Status: understood · Cluster: 8 · Convention: thiscall(SoundDevice *this (global 00442080), uint32 archiveOffset, a, b, uint16 tag) — RET 0x10
**Behaviour:** takes the next of the device's stream records (+8 pointer array, count at +0x18, incremented), seeks the archive file (0x4032e0) to the entry, reads the 0x2c-byte header and accepts it only when it has "RIFF" at 0, "fmt " at 12, format 1 (PCM) at 20 and "data" at 36 (the plain 44-byte WAV header; checked: all 2,346 WAVs in the archive are PCM mono 22050 Hz 8 bit with exactly that header). Then the record gets the data size (header +40), the file position of the data (0x403300), loads the first buffer (0x4042c0), +0x24 := tag, active byte (+0x28) := 1, sets the DirectSound buffer's format through slots 0x30/0x3c/0x40 and returns a new id (device +0x14 incremented, stored in the record at +0x2c). On a bad header the record is still used but not loaded. Buffers: 0x5622 bytes (1 s) in two halves of 0x2b11, refilled by 0x4043e0 as the play cursor crosses halves; the unused tail is filled with 0x7f (8-bit silence is 0x80). Scripts call it with (offset of NAME.WAV, 0, 0, 0). **Port:** not ported (the engine would use the mixer).
