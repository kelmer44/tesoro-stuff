# 0040ed10 — interactive object constructor (kinds 5, 9, 12, 17, 20, 6, 24 build on it)
Status: emu-compared · Convention: thiscall(Obj *this, record, room, banks, byte *data, uint stateSize)
**Behaviour:** the plain object constructor (0x401aa0), then: visible follows whether the current sequence of the first bank has a picture; flags |= collidable, in room list, hitter. Plays only the first sequence (data[0]). Approach point := position + (s16 data+2, s16 data+4); facing Jim takes on arrival := data[6] + 1; hover-name phrase from the 12-byte name at data+7 (none when its first byte is 0). Then **six** verb phrases (12-byte names from data+0x13, stride 12) go to verbs 0, 1, 3, 4, 5, 2 in that order; verb 6 is never set by the constructor (the seventh entry of the original's mapping array is unused). An empty name leaves the verb without a line.
