# 0040e000 — Kind22 SetVerbAndClick (slot 14): save/load menu actions
Status: understood · fastcall-style(this); action byte +0xa0 selects the action; returns 1 unless noted. Cursor object C = 00442128: +0x11a number of saved games (u16), +0x11c selected slot (u16, 0 none), +0x120 read buffer (0x10a40 bytes = the thumbnail), +0x124 file time, +0x128 write buffer for the thumbnail. Save file name format "isla%04i.sav" (string 0042d60c), listing mask "*.sav".
| Action | Effect |
|---|---|
| 0 | previous slot: if no saves return; if none selected select the last (+0x11a); else slot-1 (clamp: value 1 → 0 clears the buffer); loads the file's thumbnail (0x10a40 bytes) and its time stamp into C |
| 1 | next slot: wraps to "none" past the last; otherwise slot+1 and loads that file's thumbnail |
| 2 | load: if a slot is selected, reads thumbnail and a 4-byte value (Jim's data index), then Jim.LoadState (slot 9), every level of the level table 00442130..004421ec LoadState (slot 9 + 00408710), then the interface level; places Jim (00407b80) in the level named by that value, sets his facing, scroll-out of menu (004029a0) |
| 3 | save: if no slot selected, increments the count and selects the new one; writes thumbnail (C+0x128), the 4-byte value at (Jim+0x40)+0x98, Jim.SaveState (slot 10), every level SaveState (slot 10 + 00408620), interface level; closes, re-reads the thumbnail and time stamp into C; fades the display (effect 4, speed 100) |
| 5 | fade out (4, 100), clear the main object list (0040fe20 on 00442104), return 3 (a different result: menu ends) |
| 6 | 004029a0 (scroll the interface strip out) |
| 7 | toggles Jim's subtitles byte (+0x112) and sets the button animation frame to it |
Other values: nothing.
**Open questions:** whole-file layout of a saved game, meaning of return 3, how the level index is recovered in action 2 (iStack_120), flag bits of the thumbnail; the exact fread/fwrite argument order (decompiler shows size 1, count N).
**Port:** not ported.

**Save file layout (read from actions 2 and 3):** (1) thumbnail, 0x10a40 bytes (the picture of the scene captured when the menu opened; size and format not checked); (2) the slot number of Jim's level, 4 bytes (level +0x98, see the level table in STRUCTS.md); (3) Jim's state (slot 10: Jim's own SaveState 00407510); (4) for every level slot 0..46 that exists (table 00442130 up to 004421e8, in order): the level's own state (slot 10 of the level, the base Obj_SaveState) and its object records (Level_SaveState); (5) the interface level's object records only (no level state). PRINCIPAL and NUEVO are not saved. **Load** reads the same order, then Jim_EnterLevel into the level of the saved slot at Jim's loaded position, turns him to his loaded facing (+0x10c), and scrolls the strip out. Resolved: the "level index" of action 2 is the 4-byte slot in item (2).
**Port (31 Oct 2026):** `MenuButton::setVerbAndClick`: actions 5 (fade 4/100, empty the main list, return 3), 6 (scroll the interface out) and 7 (switch the subtitles and show the setting) are as read; actions 0 to 3 call the host (`previousSlot`, `nextSlot`, `loadSlot`, `saveSlot`; save then fades 4/100), which warns that saved games are not ported yet. **Validation:** actions 5, 6, 7 and the ones that do nothing (4, 8, 9, 200) compared as for 0x40df70; actions 0 to 3 not compared.
