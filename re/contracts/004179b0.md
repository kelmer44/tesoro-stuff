# 004179b0 — inferred_MapLevel_StoryUpdate (MAPA class 0042bc08, slot 13)

**Purpose (confirmed):** the island map's replacement for the "pictures reloaded" step (see 00416800): it opens places on the map once ORZOGUEI's four tasks are done. It replaces the whole base step, so the map starts **no music cue and runs no collision pass** at that moment.
**Behaviour (state record = the byte block an object's +0x60 points at):** (1) ORZOGUEI of POBLADO (level 9): if its bytes +0xb, +0xc, +0xd and +0xe are all non-zero, byte +1 := 5. (2) If CANOA of PLAYA (level 7) is not active (flags bit 1 clear) and ORZOGUEI's byte +1, as a signed byte, is above 4: CANOA is activated (slot 8, 1) and JUSTINO of VOLCAN (level 12) is deactivated (slot 8, 0). (3) If FERNAN of PANTANO (level 10) has state byte 0 equal to 0 and JUSTINO's state byte 0 is 2: FERNAN is activated. The original looks objects up again before each use (no side effect) and crashes if one is missing; the port skips the step that needs it.
**Port:** `WorldLevel::mapEvents` (world.cpp), called from `picturesReloaded` for level 8. **Validation:** `re/tools/check_map_events.py`: the original in Unicorn with the lookups and name hash as logging stubs and objects with state records, flags and a logging slot 8: 800 cases (random state bytes including 4 and values above 127, tasks done half the time): lookup order, activations, every state byte and the return value match the model (two mutations caught). The C++ is reviewed against the model, not run against the original.
