**Purpose (confirmed):** What clicking a menu item does, chosen by its action number (+0xa0). Names: "FANMMENU" (string 0042e768) is the dialogue block of the menu scripts, labels "nuevo" (0042e774), "facil" (0042e760), "dificil" (0042e758). "Start a script" = look the block and label up in the dialogue table (global 004420b8, 004060c0 with the block key, the label key, 0 and a level) and start it (00405fd0).
- 0 ("Nueva partida" of the main menu): fade out (004123e0 with 4 steps of 100 ms); Jim enters the new-game menu level (global 004421f4) at room array +0x70, position (0, 0) (Jim_EnterLevel 00407b80); start script FANMMENU/nuevo for Jim's level; returns 3.

- 2 (easy): start script FANMMENU/facil for the item's own level; returns 1.
- 3 (regular, the default difficulty): fade out; 00414560 (probably the start of the game); returns 3.
- 4 (hard): start script FANMMENU/dificil for the item's own level; returns 1.
- any other number: nothing, returns 1.
The scripts are what leave the menus and start the game: the story engine, not read yet. 3 ends the pass (a state change).
