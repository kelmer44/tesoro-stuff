# 00409280 — inferred_SweepRects (swept rectangle test)
Status: emu-compared · Cluster: 14 · Convention: cdecl(int ax1, ay1, ax2, ay2, bx1, by1, bx2, by2, dx, dy) → int

**Purpose (confirmed):** Moves rectangle A (x1, y1)-(x2, y2) by (dx, dy) and reports how it meets rectangle B (the game keeps y pointing up, so y1 is the upper edge of a hit rectangle and y2 the lower).
**Result:** 0 if they already overlap at the start, −1 if they never touch, otherwise the fraction of the movement at which they first touch, in 16.16 fixed point (0x10000 = the whole movement), computed with truncating integer division. The corner cases compare cross products of the movement with the gap to B's corner to decide whether the first contact is on a vertical edge or a horizontal one.
**Edge cases:** a zero divisor faults in the original; the port returns −1 there. Tests such as `a − b != 0 && b <= a` are `b < a`.
**Port:** engines/tesoro/core/collision.cpp::sweepRects.
**Validation:** Differential check `re/tools/run_startup_check.sh` (gen_vectors_sweep.py + drivers/sweep_driver.cpp): the original function run in Unicorn on 120000 random rectangle pairs and movements (spans 1 to 300, both y orders, zero components, B placed near A's path): 120000/120000 identical (7513 overlaps, 107340 misses, 5147 hits). Of 12 boundary mutations of the port, the 8 that change the result are caught; four (the `b <= a` forms, one `<` vs `<=` where both fractions are equal rationals, `p8 <= p2`) are equivalent mutants.
