# 00415960 — inferred_WinMain
Status: understood · Cluster: 37 · Depth: 17 · Convention: cdecl-like WinMain(HINSTANCE, prev, char *cmdline, int show); returns int (decompiler shows 4 args, cmdline in the third)

**Purpose (confirmed unless marked inferred):** Program entry after CRT startup. With an empty command line it is the CD launcher; with the argument `_$_$_` followed by a drive letter it runs the game; with `Uninstall` it runs the uninstall path; any other argument returns -1.

**Inputs:** cmdline (byte*): empty => launcher branch; first 6 bytes equal `_$_$_` plus byte 6 = CD drive letter => game branch; string equals `Uninstall` => uninstall branch. hInstance and nCmdShow go to CreateMainWindow.
**Outputs / state written:** Game branch: stores cmdline[6] into global 00442204, creates the window and subsystems, runs the message/frame loop, then Shutdown; returns 1 on normal exit or the WM_QUIT wParam. Launcher branch: returns 0 when the CD was found (SETUP.EXE launched), otherwise loops a "CD no encontrado" retry box (MB_OKCANCEL|MB_ICONQUESTION, 0x21) until Cancel, then returns -1. Uninstall branch: same retry loop with FindCdAndSetup(1).
**Calls:** FindCdAndSetup (00415b00), CreateMainWindow (00415880), InitGameWorld (00413e60), RunFrame (00414420), Shutdown (004144a0), _strncmp, MessageBoxA, PeekMessageA/GetMessageA/TranslateMessage/DispatchMessageA.
**Yields / blocks / timing:** Main loop: PeekMessage (no remove) -> if a message is pending, GetMessage; WM_QUIT (GetMessage==0) returns wParam without Shutdown; Translate/Dispatch; then RunFrame once per iteration. The loop runs RunFrame whether or not a message was pending, so frame rate is set by RunFrame content, not by a timer.
**Edge cases:** Argument matching uses the first six bytes only (`_strncmp(...,6)`); the drive letter is not validated here. The launcher message strings are Spanish. WM_QUIT skips Shutdown (process ends right after).
