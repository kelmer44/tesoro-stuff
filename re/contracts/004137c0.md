# 004137c0 — inferred_SpeechTable_Sort
Status: emu-compared · Cluster: 33 · Convention: fastcall(SpeechTable *this)

**Purpose (confirmed):** Selection sort of the entries, largest key first. Keys compare by the low half first (unsigned), then the high half; each step finds the largest key from position i on (first of equal keys kept as the candidate, a later one wins only if strictly larger) and swaps it into place. The sort is not stable; for equal keys the result is what this algorithm gives, which the port repeats.
**Port:** the sort loop of SpeechTable::load. **Validation:** see 00413570.
