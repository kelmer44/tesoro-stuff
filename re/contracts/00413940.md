# 00413940 — inferred_Phrase_Find
Status: emu-compared · Cluster: 33 · Convention: cdecl(const char *name) returns Entry *

**Purpose (confirmed):** Hashes the name (0x415c40) and searches the four speech tables of global 00442110 in order (0x4138b0); returns the first hit, a pointer to the 16 byte line. No table has it: message box "Error: frase '%s' no encontrada" (text from 0x42d6a4) and 0. Callers: the script compiler for every ` <phrase>` line (0x404810). The pointer is what a `say` command holds in [+4]; the executor passes it on to make the character speak (0x410330 / 0x407ce0).
**Port:** SpeechTables::find returns the table number in bits 24..31 and the line number, plus one (0 = none); lineOf() gives the line back. The engine's ScriptLookup::phraseId is meant to call it. No message box: the caller decides.
**Validation:** see 00413570.
