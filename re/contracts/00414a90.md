# 00414a90 — Kind02 OnAttach (slot 0)
Status: understood · fastcall(this). Allocates a list of capacity N (+0x72) at +0x74; for each stored key (+0x6c) finds the object of that name in the level (ObjectList_FindByKey on level +0x40's list) and appends it to the member list (List_InsertAfterCursor 00415200, at the end). A missing object appends null. (There is also a stack copy of seven words of the level's list header that is not used afterwards; the routine installs an exception frame.)
**Open questions:** whether a null member is later skipped (kind 11 walks the list and reads +0x5c of each).
**Port (31 Oct 2026, `codex/object-kinds`):** `ItemGroup::onAttach`.
**Validation:** Smoke check only (`re/tools/drivers/kinds_smoke_driver.cpp`, 31 Oct 2026): every kind 2, 15 and 16 object of the 50 shipped levels builds and attaches (the kind 2 group of 5 finds all members; the group of 45 depends on kind 13 objects the probe does not build); the three kind 16 sprites run 10 minutes of clock: one sets off once, with offsets up to 411, no warnings.
